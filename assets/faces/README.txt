CLASSMATE FACES
===============
Put a square-ish photo here, named after the flower id, to replace its placeholder face:

    flower_01.png   (Daisy)        flower_16.png   (Cosmos)
    flower_02.png   (Buttercup)    ...
    flower_30.png   (Rainbow Bloom)

Accepted: .png .jpg .jpeg  (any size; it is cropped to a circle and drawn on the flower).
If a file is missing or broken, the game simply shows a generated placeholder face.
The full id -> flower list is in src/FlowerRegistry.java (flower_01 = first row of the table, etc.).
