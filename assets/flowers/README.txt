CLASSMATE FACES
One transparent PNG per character, named after the flower id in src/FlowerRegistry.java:
  Rare:      brent.png  rovid.png  paolo.png  klent.png
  Legendary: aron.png   zeus.png   gudo.png
The PNG is the FACE ONLY (about 35x35 px, exported from Resprite). The game draws the petals around it,
in the colour set in FlowerRegistry, and draws the stem and growth stages itself.
Keep the pixel size you drew at (do not upscale on export) - the game scales it and keeps it crisp.
A missing file = the game draws a cute face itself (skin / hair set in FlowerRegistry). That is how the
commons (daisy, tulip, ...) get their faces - they have no file here.
