ICONS
PNGs here replace the icons the game would otherwise draw in code (square, transparent background):
  fert_worm.png    purple potion = Worm Fertilizer    (in use)
  fert_manure.png  red potion    = Manure Fertilizer  (in use)
  worm.png         the worm that crawls on plots with Worm Fertilizer (in use; no file = no worm)
  coin.png, seed_bag.png                              (optional - not supplied yet, drawn in code)
A missing file = the built-in drawn icon.
